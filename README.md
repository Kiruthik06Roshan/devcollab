# DevCollab

DevCollab is a modern SaaS collaboration platform for student developer teams. This repository is scaffolded as a two-app workspace:

- `frontend` - React + Vite + Tailwind + React Router + shadcn/ui foundation
- `backend` - Node.js + Express + MongoDB + Socket.IO + JWT foundation

The current phase is architecture only. Features are intentionally stubbed so the codebase can grow cleanly into production modules.

See [ARCHITECTURE.md](ARCHITECTURE.md) for the full project structure, route map, data model plan, socket plan, and recommended delivery order.
